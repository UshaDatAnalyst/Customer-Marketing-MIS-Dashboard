# Customer Marketing MIS Dashboard

## Project Overview

This project is an Excel-based MIS Dashboard developed to analyze customer demographics, spending behavior, and marketing campaign performance.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* KPI Cards

## KPIs

* Total Customers
* Total Revenue
* Average Income
* Campaign Acceptance Rate
* Average Spending per Customer
* Complaint Rate

## Key Insights

* Graduation customers form the largest customer segment.
* Married customers generate the highest revenue.
* Customers aged 50+ contribute the highest spending.
* Campaign acceptance rate is approximately 15%.

## Dashboard Features

* Interactive Slicers
* Customer Segmentation
* Revenue Analysis
* Age Group Analysis
* Dynamic KPI Reporting
